# Lawyer AI Assistant v0.1.0

## Release Summary

Version `v0.1.0` is the first documented backend demonstration release of
Lawyer AI Assistant.

The release provides a production-oriented Spring AI Agent backend with
authentication, tenant isolation, MCP-based legal tools, RAG retrieval, Redis
caching, evaluation, cost attribution, and operational observability.

The browser frontend is maintained as a separate project and is not included
in this release.

## Highlights

- Java 21 and Spring Boot backend;
- Spring AI Agent runtime;
- structured planning, action selection, tool execution, reflection, and final
  answer generation;
- MCP Agent and MCP Server runtime-role separation;
- legal RAG with Ollama Embedding;
- document metadata, checksums, versioning, duplicate prevention, and
  incremental synchronization;
- Redis Tool and retrieval caches;
- Caffeine fallback for local development;
- Redis fail-open behavior;
- JWT authentication;
- trusted tenant identity restoration;
- MyBatis, MySQL, and Flyway persistence;
- deterministic evaluation;
- optional LLM-as-a-Judge evaluation;
- token usage and model cost attribution;
- cost and performance guardrails;
- Prometheus and Grafana observability;
- ArchUnit architecture regression rules;
- production Docker Compose deployment.

## Runtime Roles

### MCP Agent

The MCP Agent owns:

- authentication;
- tenant context;
- Agent orchestration;
- legal Tool invocation;
- evaluation;
- token and cost metrics;
- public HTTP APIs.

### MCP Server

The MCP Server owns:

- legal MCP Tool exposure;
- RAG retrieval;
- knowledge-base synchronization;
- Embedding integration;
- Vector Store access.

## Evaluation Baseline

The documented Day22 full evaluation baseline completed:

- 5 evaluation cases;
- 5 passed cases;
- 100% pass rate;
- average deterministic score of 98;
- complete token-usage coverage;
- complete pricing coverage.

Model output is non-deterministic. Future executions may produce different
scores, token counts, durations, and costs.

## Security Boundary

This release includes:

- stateless JWT authentication;
- tenant identity derived from validated JWT claims;
- role-based access control;
- MCP Tool authorization policies;
- prompt-injection and sensitive-output guardrails;
- runtime resource limits;
- explicit CORS origin configuration;
- sanitized external error responses.

No production credentials are included in this repository.

## Known Limitations

- the current HTTP Agent endpoint is a demonstration Playground API;
- the frontend is maintained separately;
- access-token revocation and refresh-token rotation are not implemented;
- the default Vector Store is not intended as a large-scale production vector
  database;
- live evaluation can be slow and can incur provider cost;
- model output quality and latency depend on external model availability;
- production deployment requires real secret management and TLS termination;
- horizontal scaling requires additional coordination for stateful runtime
  concerns.

## Upgrade and Compatibility

This is the initial public backend release. No upgrade migration from an older
public release is required.

Future breaking changes must update:

- the frontend API contract;
- the Postman Collection;
- the final baseline;
- architecture tests;
- release notes.
